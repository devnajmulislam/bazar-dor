# BazarDor (বাজার দর)

BazarDor is a friendly web application that helps people check daily market prices easily. Therefore, users can plan their shopping budget before going to the market.

## Tech Stack

* **Next.js** (React Framework)
* **TypeScript**
* **Tailwind CSS** (Global Styles)
* **Better Auth** (Authentication System)

## Key Features

* **User Authentication:** Users can quickly sign up and sign in to access their accounts.
* **Product Details:** In addition, users can click on products to see full details and current market prices.
* **Category Filtering:** Items are organized by categories so people can find things easily.
* **User Profile Page:** Also, logged-in users can view and manage their profile information.
* **Interactive UI:** Lastly, the website includes cool announcement marquees, top banners, and neat navigation links for smooth browsing.
